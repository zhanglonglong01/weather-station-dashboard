# 东北旺试验田演示场景

界面以“东北旺试验田气象站管理”为演示业务场景。当前页面使用历史样本，**不表示本项目或实验室已在该试验田布设设备并采集这些记录**。

为了突出站点管理与查询功能，首页不再展示大幅数据来源介绍；原始数据的作者、许可、DOI、固定版本、时间范围和处理方式继续保留在 [数据来源说明](DATA_SOURCES.md)、README 及数据清单中。

前端站点别名仅为演示分区：

| 前端演示名称 | 原始站点代码 | 真实数据集站点 |
|---|---|---|
| 示例气象站 A | ES-ALAVA | Álava |
| 示例气象站 B | ES-NAVARRA | Navarra C0 |
| 示例气象站 C | ES-CARTAGENA | Cartagena C0 |

别名只作用于前端显示。API、数据库、CSV 导出中的原始站点代码、观测时间和来源字段不变；不改写历史日期、不伪造地理位置字段、不修改记录的来源。

如果后续接入真实东北旺试验田采集记录，应新增具有实际站点名称的站点，通过数据接入 API 导入，并对采集时间、物理量单位与设备编号进行核对。实际数据接入前，界面保持“历史样本演示”标识。
